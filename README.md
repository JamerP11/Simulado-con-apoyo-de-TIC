# Sistema de Gestión de Reservas

Este proyecto implementa un sistema orientado a objetos en Python 
para gestionar clientes, servicios y reservas sin uso de bases de datos.

## Características
- Uso de herencia, polimorfismo y encapsulación.
- Manejo de excepciones personalizadas.
- Registro de errores en archivo logs.

## Ejecución
python main.py
