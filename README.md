# Sistema de Gestión de Clientes, Servicios y Reservas

Proyecto en Python basado en Programación Orientada a Objetos.

## Características
- Uso de herencia, polimorfismo y encapsulación.
- Clases abstractas.
- Manejo de excepciones personalizadas.
- Registro de errores en archivo logs.txt
- Simulación de operaciones válidas e inválidas.

## Estructura
- cliente.py → gestión de clientes.
- servicio.py → tipos de servicios.
- reserva.py → gestión de reservas.
- excepciones.py → manejo de errores.
- main.py → ejecución del sistema.

## Ejecución
```bash
python main.py
